# 00 · 新用户请先看这里

> 玉子控制台（Yuzu Console）— 基于 NapCat + DeepSeek 的 QQ 数字助手
> 版本 0.3.7 · 2026-10-20 · 面向 Windows 10 / 11

这份文件给两种人看：

- **人**：照着做就行，每一步都写了「你会看到什么」。
- **AI（比如你丢给对方的 DSH）**：直接跳到 [第三部分](#第三部分给-ai-同事的说明书)，那里是路径、端口、命令和故障表。

---

## 第一部分 · 这玩意儿到底是什么

一句话：**让你的 QQ 号自己会说话、会干活。**

- 你在手机上给某个 QQ 小号发消息，几秒后它用「玉子」的身份回你；
- 它能看图、看视频（抽帧）、听语音（转文字）、查资料、跑命令、读文件、发文件给你；
- 它会每天帮你汇总学校群消息、整理作业/考试/通知，发 QQ 空间时自动点赞评论。

### 你需要准备的四样东西

| 要什么 | 说明 | 能不能省 |
|---|---|---|
| 一台 Windows 10/11 电脑 | 常开机更好，睡眠会掉线 | 不能 |
| 一个 **QQ 小号** + 手机 QQ | 专门给玉子用，**千万别用主号** | 不能 |
| DeepSeek API Key + 余额 | 到 platform.deepseek.com 充值，10 块钱能聊很久 | 不能 |
| 管理员权限 | 安装器要写启动项、注册计划任务 | 只在安装时需要 |

### 必须先知道的风险

> 用协议端登录个人 QQ 属于**非官方自动化**，腾讯有权判定违规并**冻结或封禁账号**。
> 所以：**只挂小号，主号一次都别登**；别群发广告、别高频加人。
> 这个风险我不替你承担，请你自己确认接受后再装。

## 第二部分 · 安装（两条路，选一条）

### 路线 A：电脑上已经装过玉子（升级 / 重装）

双击：

```
01-安装包\安装玉子控制台.exe
```

会弹 UAC 确认框（蓝色盾牌），点「是」。然后看到 7 个步骤：

```
复制程序文件到 qq-bridge    ✓
复制托盘程序到 玉子软件开发   ✓
写启动脚本到 C:\DSH         ✓
建桌面 / 开始菜单快捷方式     ✓
注册开机自启（注册表）        ✓
注册每 2 分钟自检任务        ✓
启动控制台                  ✓
完成：7 步成功，0 步失败。
```

看到「7 步成功，0 步失败」就是装好了。**任何一步打红叉，把整段文字复制给我。**

已有的 `.env`、`data\`（聊天记录、好友白名单、备份）不会被覆盖，放心。

装完验证：双击桌面的「玉子控制台」，右下角托盘会出现玉的图标，控制台窗口里六个卡片应该是绿的。再双击 `检查安装.bat`，它会跑 13 项检查并打印 `全部通过`。

### 路线 B：全新的电脑（从零开始）

1. 把整个 `玉子项目开发-安装测试` 文件夹拷过去（U 盘 / 网盘都行）。
2. 右键 `02-部署工具\部署.ps1` → **以 PowerShell 运行**（或在 PowerShell 里执行 `powershell -ExecutionPolicy Bypass -File .\部署.ps1 -Target "D:\Yuzu"`）。
3. 它会自动做这些事：
   - 检查并下载 Node.js（没有就下载官方安装包静默装）
   - 检查并下载 ffmpeg（77MB，视频抽帧用）
   - 检查并下载 QQ 9.9.33 安装包（314MB）——**这一步需要你手动点几下确认**
   - 下载 NapCat Shell 并解压到 `D:\NapCat\NapCat.52230.Shell`
   - 把玉子的程序复制到目标目录、替换所有写死的路径、重新编译托盘
   - 生成 `.env`（会问你要 QQ 号和 API Key）
4. 最后一步：**手机 QQ 扫码登录小号**。控制台里会直接显示二维码，扫完就通了。

> 路线 B 里「QQ 静默安装」和「NapCat 覆盖安装」这两段我还没在干净机器上跑过全流程，如果卡住，把屏幕截图发我，我改脚本。

### 装完之后：第一次跑通

1. 手机 QQ 登录**小号**（不是主号）。电脑上控制台 → 总览 → NapCat 卡片点「启动」；
2. 卡片上会写「等待扫码登录」，下面出现二维码 → 手机扫码确认；
3. 看到 NapCat 卡片变绿（运行中），说明 QQ 协议端好了；
4. 用**你自己的主号**去加这个号好友，发一句「在吗」；
5. 几秒内应该收到「在呢主人」之类的回复。

没有回复就看 [故障表](#故障表按顺序查)。

## 第三部分 · 给 AI 同事的说明书

> 你（AI）现在被要求帮忙部署或排障「玉子控制台」。请先读完本节再动手。

### 3.1 它由四块组成

| 组件 | 位置 | 端口 | 作用 |
|---|---|---|---|
| NapCat（QQ 协议端） | `D:\NapCat\NapCat.52230.Shell` | 3001（OneBot WS）、6099（WebUI） | 真的登录一个 QQ 号，对外提供 OneBot11 接口 |
| 玉子 bot | `D:\DeepSeek test\qq-bridge\bot.mjs` | 3008（单例锁） | 收消息、调模型、调工具、发回复 |
| 空间监听 | 同上 `qz_watch.mjs` | 3009（单例锁） | 每 60 秒看一次说说，自动点赞评论（走无头 Edge + CDP） |
| 玉子控制台 | `D:\DeepSeek test\玉子软件开发` | 3210（HTTP）、9556（窗口 CDP） | 图形界面：启停服务、看记录、调试、设置 |

旁路：`msedge.exe --headless=new --remote-debugging-port=9333`（给空间点赞用）。

### 3.2 数据都在哪

### 3.3 开机自启链路（三层，任何一层坏都还能起来）

1. 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
   - `DSH_AutoStart` → `wscript.exe "…\dsh-startup.vbs"`（等 15 秒拉起 DSH）
   - `QQBridge_AutoStart` → `wscript.exe "…\qq-bridge-startup.vbs"`（等 20 秒跑 autostart.bat）
2. 计划任务 `QQBridge-KeepAlive`：每 2 分钟执行 `C:\DSH\run-bridge.exe`
   - `run-bridge.exe` 是无窗口启动器（编译自 `C:\DSH\RunHidden.cs`），它去跑 `C:\DSH\run-bridge.bat`
   - `run-bridge.bat` = 先 `start-console.ps1`（保证 3210 活着）→ 再 `autostart.bat`
3. 手动：控制台「全部启动」，或直接 `cmd /c C:\DSH\run-bridge.bat`

`autostart.bat` 的逻辑（幂等，随便重跑）：

- 有 `data\runlock` 且 4 分钟内 → 跳过本轮
- 先起控制台 / bot / 空间监听（探 3210 / 3008 / 3009）
- 3001 已监听 → 直接结束
- 二维码 5 分钟内刚生成 → 认为在等人工扫码，**不重启 NapCat**（避免反复掉登录）
- 否则按 3 分钟冷却决定要不要重启 NapCat；后端僵死才硬重启，最多两轮

### 3.4 常用动作（PowerShell）

```powershell
# 看六个服务状态
(Invoke-WebRequest http://127.0.0.1:3210/api/status -UseBasicParsing).Content

# 自检（10 项）
(Invoke-WebRequest http://127.0.0.1:3210/api/doctor -UseBasicParsing).Content

# 缺什么补什么
Invoke-WebRequest http://127.0.0.1:3210/api/doctor/fix -Method POST -UseBasicParsing

# 端口探活
foreach ($p in 3001,3008,3009,3210,9333) { "$p = " + (Test-NetConnection 127.0.0.1 -Port $p -InformationLevel Quiet) }

# 跑自测（50 项）
node "D:\DeepSeek test\qq-bridge\test-console.mjs"

# 打备份
node "D:\DeepSeek test\qq-bridge\backup.mjs" my-tag
```

控制台 HTTP 接口清单（全部 GET，除标注 POST）：

| 路径 | 作用 |
|---|---|
| `/api/status` | 六服务探活 + 进程详情 |
| `/api/history?limit=200&ch=qqall&q=关键词` | 聊天记录（`qqall` = 只 QQ 侧） |
| `/api/history/export?…` | 导出 txt |
| `/api/debug/info` | 登录号 / 好友 / 群 / 白名单 |
| `POST /api/debug/send` `{uid,text}` | 发私聊 |
| `POST /api/debug/group` `{gid,text}` | 发群 |
| `POST /api/debug/qzone` `{op,text}` | 空间点赞 / 评论 |
| `/api/setup` | 环境自检 9 项 |
| `POST /api/setup/action` `{op}` | op = ffmpeg / shortcut / autostart / napcat / installer / build / launch |
| `/api/doctor` `/api/doctor/fix` | 自检 / 一键修复 |
| `/api/usage` `/api/balance` `/api/weather` | 用量 / 余额 / 天气 |
| `/api/backups` | 备份列表（POST 可创建或回滚） |
| `/api/update` | 读 `updates\version.json` 检查升级 |

### 3.5 故障表（按顺序查）

| 症状 | 先看什么 | 常见原因 / 处理 |
|---|---|---|
| 控制台打不开 / 白屏 | `Test-NetConnection 127.0.0.1 -Port 3210` | 3210 没起 → `start-console.ps1`；起了还白 → 控制台会自己 reload，仍不行就杀 `WINDOWTITLE eq 玉子控制台` 的 msedge 再双击图标 |
| QQ 发消息没人回 | `data\bot.out.log` 末几行 | 出现 `❌ 断开` → 3001 没开，去控制台启 NapCat；出现 `✅ 已连接` 但没回 → 看白名单（`.env` 的 OWNER_QQ / EXTRA_WHITELIST） |
| NapCat 启动后没 3001 | `data\boot.log` + `qrcode.png` 时间 | 掉登录了，要手机扫码。控制台会显示二维码，点「换一张二维码」可热刷新 |
| 反复弹黑窗口 | 计划任务动作 | 动作必须是 `C:\DSH\run-bridge.exe`（不是 cmd.exe /c …），否则每 2 分钟闪一次 |
| 每 2 分钟控制台重开 | `tray.log` | 托盘单实例：第二次双击只是「唤起」，属正常 |
| 安装器某步红叉 | 安装器日志 + `install.log` | 缺 `payload\` → 双击 `01-安装包` 里那份 exe；写 C:\DSH 被拒 → 没弹 UAC，右键「以管理员身份运行」 |
| 空间不点赞 | `data\qzone.log` | 9333 没起（无头 Edge 挂了）→ 控制台启「无头 Edge」；cookie 过期 → 重启 NapCat 重登 |
| 回复很慢 | `data\usage.jsonl` | 工具多轮 / 全盘搜索会慢；`MODEL=deepseek-flash` 带推理，短问题也吃 1.5 秒 |

### 3.6 铁律（别做这些）

1. **不要**用主号挂 NapCat，一个 NapCat 只登一个小号。
2. **不要** `taskkill /f /im QQ.exe` 无脑全杀——会顺手杀掉日常 QQ，也会让下次登录掉凭据。
3. **不要**把 `DEEPSEEK_API_KEY` 贴进聊天记录、日志、截图。
4. **不要**在没备份时改 `.env`：改之前控制台会自动备份一份，也可以手动 `node backup.mjs`。
5. 迁移到新电脑时，`D:\NapCat` 与 `D:\DeepSeek test` 这两个路径可以改，但改完要同步改 `.env`、`autostart.bat`（`NAP=` 与 `C:\DSH` 两处）、`dsh-startup.vbs`、`qq-bridge-startup.vbs`、`web\index.html` 里的桌面路径。**部署器已经会自动替换这些**，手改容易漏。

## 第五部分 · 卸载

```powershell
# 1) 去掉开机自启与自检任务
cmd /c "D:\DeepSeek test\qq-bridge\remove-autostart.bat"

# 2) 退出托盘（右下角图标右键 → 退出托盘），然后删目录
Remove-Item "D:\DeepSeek test\qq-bridge" -Recurse -Force
Remove-Item "D:\DeepSeek test\玉子软件开发" -Recurse -Force
Remove-Item "C:\DSH" -Recurse -Force
# NapCat 与 QQ 按普通软件卸载
```

删之前把 `data\brain\messages.jsonl` 和 `.env` 复制出来，那是你的记录和配置。
