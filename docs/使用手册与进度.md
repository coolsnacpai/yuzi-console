## 一、怎么打开

三种方式，随便挑：

1. 双击 `D:\DeepSeek test\玉子软件开发\玉子控制台.exe`（有托盘图标，右键有菜单）
2. 托盘图标右键 →「打开控制台」
3. 浏览器直接开 `http://127.0.0.1:3210`

控制台自己也受开机自启保护：`C:\DSH\run-bridge.bat` 每 2 分钟自检一次，发现托盘没起来就拉起来。

## 四、天气推送与峰谷

**天气推送**（`bot.mjs` 里，不调模型，0 token）
- 每天到 `WEATHER_AT`（默认 `07:30`）私聊主人一条：「武汉今天毛毛雨，17.2~19.9℃，降水概率100%，记得带伞。」
- 开关：`.env` 里 `WEATHER_ON=0` 关；城市 `WEATHER_CITY=wuhan`；改城市要在 `bot.mjs` 的 `CITY` 表里补坐标。
- 当天只推一次，状态存 `data/weather_state.json`。

**余额与峰谷**
- 余额：`GET https://api.deepseek.com/user/balance`，5 分钟缓存。
- 峰谷：高峰 9:00–12:00、14:00–18:00 原价，其余时段半价（0.5 倍），官方 2026-08-17 生效。
- **周末全天空闲**做成了开关 `weekendOffPeak`，默认 `false`（官方公告没提），确认后改 `data/pricing.json` 为 `true` 即可，不用改代码。

## 七、排错对照表

| 现象 | 先看哪 | 处理 |
|---|---|---|
| 控制台打不开 | `data\console.log` | `Get-Process -Name 玉子控制台`；没有就双击 exe |
| 页面状态灯全红 | `data\boot.log` | 等 2 分钟自检，或手动跑 `C:\DSH\run-bridge.bat` |
| QQ 不回消息 | 3001 是否监听 | 跑 `autostart.bat`，看是否要扫码（总览页会显示二维码） |
| 空间不点赞 | `data\qzone.log` | 检查 9333 端口 / 无头 Edge 是否活着 |
| 余额读不到 | 设置页提示 | key 失效或断网；改 `.env` 后重启 bot |
| 改完配置没生效 | — | `.env` 改完要重启对应服务（总览页「重启」按钮） |
| 双击 exe 没窗口 / 窗口只有一片空白 | `data\tray.log` | ①已开着实例时，第二次启动只会写 `data\open.request` 唤起窗口；②窗口标题若是 `127.0.0.1_/`，说明 Edge 渲染进程在 AppContainer 里连不上回环地址，托盘已用 `--disable-features=RendererAppContainer` 规避，别手动去掉 |
| 状态灯误报「已停止」 | — | v0.3.1 起改用 `tasklist` + 端口探活（原来走 WMI/PowerShell，慢且可能被拒），刷新一次就恢复 |

### 做了什么

### 为什么安装包要 UAC
实测发现：本机编译出的 exe **直接写 `C:\` 和 `HKCU` 注册表会被系统拒绝**（`UnauthorizedAccessException` / `SecurityException`），连它拉起的 powershell 子进程也继承同样的限制。所以安装包内嵌了 `requireAdministrator` 清单——双击时点「是」即可，装完就不再需要管理员。

### 用法
1. 双击 `dist\玉子控制台-安装包\安装玉子控制台.exe` → UAC 点「是」→ 点「开始安装」。
2. 安装日志在 `D:\DeepSeek test\玉子软件开发\install.log`。
3. 换电脑 / 重装：整个 `dist\玉子控制台-安装包` 文件夹拷过去双击即可（目标机需要先装 Node 24、Edge、NapCat）。
4. 静默安装（装机脚本用）：`安装玉子控制台.exe /silent`，结果看 `install.log` 最后一行 `SILENT DONE ok=N fail=M`。

### v0.3.6.1 修补（2026-10-20 21:5x）

1. **安装包"缺 payload"修好了**：以前 exe 只会找自己同目录的 `payload\`，你在根目录点了那份 exe 就报"安装包里缺 payload\bridge"。现在会依次找：

2. **每 2 分钟闪黑窗口修好了**：原因是计划任务直接跑 `cmd.exe /c run-bridge.bat`，cmd 每 2 分钟弹一次控制台。
   现在改成 `C:\DSH\run-bridge.exe`（GUI 子系统的静默启动器，源码 `C:\DSH\RunHidden.cs`），它用

3. 顺带修：安装程序"注册计划任务"这一步以前失败也报 ✓，现在会明确 ✗ 并提示需要管理员。
### v0.3.6.2 修补（2026-10-20 22:0x）

**上一版安装包是我把清单弄丢了**：为了换个图标重新编译时漏了 `/win32manifest`，结果 exe 变成"普通权限"，双击不弹 UAC，于是写 `C:\DSH`、写 `HKCU` 注册表、建计划任务全被系统拒绝——就是你截图里那四条红。

修法（双保险）：
1. 重新嵌回 `src\setup.manifest`（`level="requireAdministrator"`），双击必弹 UAC；
2. 程序自己再检查一次：不是管理员就用 `Verb=RunAs` 把自己重新拉起来，用户取消就弹提示「请右键以管理员身份运行」。
3. 计划任务那步改成直接用 `%SystemRoot%\System32\schtasks.exe` 并打印真实返回码，失败会带原始报错，不再只说"失败"。

正确编译命令（以后照这个来）：
```
csc /nologo /codepage:65001 /target:winexe ^
    /win32manifest:"src\setup.manifest" ^
    /win32icon:"assets\yuzu.ico" ^
    /out:"安装玉子控制台.exe" src\Setup.cs
```
注意：带了这个清单之后，`/check` 和 `/silent` 被双击时也会先弹 UAC（Windows 在进程启动前就要提权），属于正常。

## 十二、全新电脑部署（v0.3.7 / deploy）

安装包本身只有 **0.39MB**（代码 + 托盘源码 + 部署器），NapCat/QQ/Node/ffmpeg 都是部署时下载。
所以"把包发给别人就能用"这件事，靠的是 `部署.ps1` 这个引导器，不是包里的文件。

### 部署器做什么

| 步 | 动作 |
|---|---|
| 1 | 检查管理员 / 磁盘（需 6GB）/ 选安装根目录（有 D 盘用 `D:\Yuzu`，否则 `C:\Yuzu`） |
| 2 | 下载 Node 24 便携版（系统已有 node 则复用） |
| 3 | 下载 ffmpeg（失败不致命，之后控制台可补） |
| 4 | 下载 QQ 9.9.33 官方安装包并静默安装，或 `-QqDir` 复用已有 QQ |

## 十四、v0.3.8 · 人格调试（记忆包 / 性格包）

**位置**：控制台顶栏「人格」。

### 记忆包（.yzm）
- **导出**：`GET /api/mem/export?scope=all|chat|owner`，产出 gzip 压缩的 JSON（扩展名 `.yzm`）。
  - 结构：`{format:"yuzu.memory", version:1, createdAt, source:{ownerQQ,count,names}, messages:[[时间戳, 渠道码, 角色, 文本], ...]}`
  - 渠道码：`o`=主人私聊、`f`=好友私聊、`g`=群、`u`=电脑端。三元组数组把字段名全省掉，同样内容比明文 JSON 小 60%～75%（实测 210KB → 22KB）。
  - 安全：只有文本与时间戳，**不含** API Key、cookie、文件路径。
- **导入**：`POST /api/mem/preview`（先看包里有什么）→ `POST /api/mem/import {data, mode:'merge'|'replace'}`。
  - `merge` 用 `时间+渠道+文本哈希` 去重，重复导入不会膨胀；`replace` 覆盖前先自动备份。
  - 兼容性：也接受未压缩的 `.json`；老格式（对象数组 `{t,ch,role,text}`）自动识别。
- **给新用户**：把 `.yzm` 给对方 → 在控制台「人格 → 选择记忆包导入 → 合并」即可续上同一份记忆。

### 性格包（.yzp）
- **导出**：`GET /api/persona/pack`，包含 `persona.md` 正文 + `style` 风格档案。
- **上传人设文件**：`POST /api/persona/import {data, useAI}`，支持 `.yzp` / `.md` / `.txt`。
  - `useAI=true`（默认）：把文本丢一次模型，结构化出 `name / callUser / tone / length / emoji / quirks / forbid / extra`；
  - `useAI=false`：用正则规则推断（不花 token），名字、称呼、「不要超过两句」「不用表情符号」这类都能抓到。
  - 导入前自动 `backup('pre-persona-import')` + 单文件快照到 `data/persona-backup/persona-<时间>.md`。
- **风格档案**：`GET/POST /api/persona/style`、`POST /api/persona/style/reset`。落盘 `data/style.json`；`styleBlock()` 生成一段「风格要求」拼进每条回复的 system prompt。
  - 生效方式：`bot.mjs` 按 `style.json` 的 mtime 热加载，**改完不用重启**。
- **界面**：名字、称呼、语气、回复长度、口癖、绝对不说、其它硬要求、是否允许表情符号，逐项可改；下方实时预览拼进提示词的那段文字。

## 十五、v0.3.9 · 文档格式（docx / doc / rtf）

记忆包和性格包都支持 Word 文档了，导出给人看、导入喂给新机都行。

### 导出格式

| 功能 | 格式 | 说明 |
|---|---|---|
| 记忆 | `.yzm` | 记忆包（gzip+JSON），体积最小，能原样回导，也能量身给新用户 |
| 记忆 | `.docx` | 真 Word（zip+XML），给人看 / 打印 / 编辑 |
| 记忆 | `.doc` | 同一份内容用 RTF 写，老版 Word、WPS 都能开 |
| 性格 | `.yzp` | 性格包（人设 + 风格档案），能原样回导 |
| 性格 | `.docx` / `.doc` | 正式文档，适合存档 / 交接 |
| 性格 | `.md` | 纯文本，方便贴给别的 AI |

- 实测体积：427 条记忆 → `.yzm` 22KB、`.docx` 约 100–200KB（deflate 压缩后）、`.doc` 约 100KB。
- `docfmt.mjs` 是自己手写的零依赖 zip + deflate + RTF 读写，不引任何第三方包。

### 导入支持

- 记忆：`.yzm`（识别成记忆包，会去重合并）、`.docx`、`.doc`、`.rtf`、`.md`、`.txt`
- 性格：`.yzp`、`.docx`、`.doc`、`.rtf`、`.md`、`.txt`

文档导入的规则：

1. 先看是不是记忆包/性格包（gzip 魔数，或 JSON 里带 `format` / `messages` 字段）；
2. 不是包就走文档路径，按段落切条，每段算一条记忆，渠道标记为 `doc`；
3. 性格文档导入 = 把正文当人设正文，带「名字／称呼／语气／口癖」等字样的行会被顺手识别进风格档案。

### 界面

- 人格页每个卡都多了一个格式下拉框，导出前先选格式。
- 两份卡底部都有「支持哪些格式？点开看」的折叠说明（`<details>`），不占地方。
- 导入框的 `accept` 已经放开到 `.yzm/.json/.gz/.docx/.doc/.rtf/.md/.txt`。

### 接口变更

| 接口 | 变更 |
|---|---|
| `GET /api/mem/export` | 新增 `fmt=yzm\|docx\|doc` |
| `GET /api/persona/pack` | 新增 `fmt=yzp\|docx\|doc\|md` |
| `POST /api/mem/import` | 非记忆包时当文档处理，返回 `{asDoc:true, paras}` |
| `POST /api/persona/import` | 非性格包时先抽文本再当人设导入 |

## 十六、v0.3.15 · 群聊白名单（输入群号就自动回）

控制台「调试台」页最上面新增一张「群聊白名单」卡片：

- 填群号 → 「加入白名单」：这个群里任何人说话，玉子都会接；下面还能点「群里见过的其他群」一键加入（名字来自 NapCat 群列表）。
- 每个群一行，「移出」即取消自动回复；「收到 N 条」和最近一句话用来确认监听正常。
- 「回复方式」三档：每句都回 / 只回 @ / 不回；「冷却秒」控制同一个群两次回复的最小间隔（默认 45，现在设 20）。

实现要点：

- 后端 `GET/POST /api/groups`（op=add | del | mode），直接改 `.env` 的 `WATCH_GROUPS` / `GROUP_REPLY` / `GROUP_COOLDOWN`。
- `bot.mjs` 新增 `refreshWatchGroups()`：每 30 秒对一次 `.env`，群消息到达时也顺手对一次（10 秒节流），所以**加完群最多 10~30 秒生效，不用重启 bot**，日志会打 `[群白名单] 已热加载：…`。
- 群号和回复模式是两件事：群不进白名单，玉子连消息都不记；进了名单才按「回复方式」决定回不回。
- 群消息会写进 `data/feed.jsonl`，同时参与每天 21:30 的日程汇总。

坑：群号必须填 NapCat 登录的那个小号**真的在**的群；不在群里是加不进去也收不到消息的。
